STAT 2050 Project: The Class Profile

Instructor & Student Guide

Project Overview

  • Data Source: The Stat2050_Survey_ResultsSP2026.csv file (available in Canvas Modules).
  • Submission Format: You may create your project however you like! Some suggestions include Microsoft products (Word, PowerPoint, Excel) or Google products (Docs, Slides, Sheets). The only restriction is that your final project must be exported and uploaded as a PDF document to ensure your formatting, graphs, and tables are preserved accurately for grading.
  • Methods Section: For each phase, you must include a brief "Methods" paragraph explaining how you created your statistical summaries (e.g., "I used the 1-Var Stats function on my TI-84," or "I used Excel formulas to sort the data").
Academic Integrity & AI Policy:
This project must be your own original work. The use of Artificial Intelligence (AI) tools (such as ChatGPT, Gemini, etc.) to generate text, analysis, or calculations is strictly prohibited and will be treated as academic dishonesty.

Exception: You may use tools like Grammarly or other software solely for spell-checking and sentence structure improvements. However, all Data Analysis must be your own work.

Phase 1: Data Cleaning & Descriptive Statistics

Focus: Data integrity, visualization, and measures of center.

Student Instructions

Step 1: Data Cleaning

Open the class data file in Excel, Google Sheets, or StatCrunch. Correct the following before analysis:

  1. Height Variable: Convert all heights to total inches (e.g., 5'7" becomes 67).
  2. Pulse Variable: Remove any text (like "bpm") so the column contains only numbers.
  3. Categorical Cleanup: Check "Eye Color." If a color has fewer than 2 entries, rename it to "Other."

Step 2: Organizing the Data

  • Create distribution tables for the Height_Inches variable.
  • Requirement: The tables must include both Frequency and Relative Frequency.
  • Grouping: You must group this data by Gender (e.g., separate columns or sections for Men and Women) to facilitate comparison.

Step 3: Visualizing the Data

Create the following graphs. Ensure every graph has a title and labeled axes.

  1. Histogram: Use your frequency distribution to create a histogram for Height_Inches.
  2. Bar Graph: Create a bar graph for the Math Anxiety Rating. (Note: Pie charts are not accepted for this assignment).
  3. Comparative Boxplots: Create side-by-side boxplots for Height_Inches. Specifically, create one boxplot for males vs. height and one for females vs. height.

Step 4: Numerical Summaries & Reflection

Calculate the following statistics for Height_Inches. Create three separate summary tables: one for the full class, one specifically for males, and one specifically for females.

  • Mean (x̄sample mean, x-bar)
  • Median (MMedian)
  • Mode
  • Range
  • Standard Deviation (ssample standard deviation, s)
  • Five-Number Summary: Min, Q1, Median, Q3, Max.

Reflection: After calculating these statistics, write a brief reflection discussing the differences you observe between the male and female summary statistics.

Step 5: The Personal Connection

  • Calculate: Find the z-score for your own height using the class mean and standard deviation.
  • Requirement: You must include the z-score calculation (show the formula with your numbers plugged in) as well as the final result.
  • Interpret: Explain what this z-score tells you. Are you considered "unusual" (more than 2 standard deviations away from the mean)?

Step 6: Methods Section

Write a brief paragraph explaining the tools and steps you used to calculate the statistics above. Crucially, you must comment on any data cleanup challenges you encountered.

📋 Phase 1 Submission Checklist:
  • Frequency and Relative Frequency tables for Height (grouped by gender).
  • Histogram for Height, Bar Graph for Math Anxiety, and Comparative Boxplots for Height by Gender (all titled and labeled).
  • Three summary statistic tables (Full Class, Males, Females) containing Mean, Median, Mode, Range, Standard Deviation, and 5-Number Summary.
  • Reflection paragraph comparing male and female summary statistics.
  • Your personal height z-score calculation and interpretation.
  • Your Methods section paragraph (including data cleanup comments).
