Phase 1: Data Cleaning & Descriptive Statistics

Focus: Data integrity, visualization, and measures of center.

Student Instructions

Step 1: Data Cleaning

Open the class data file in Excel, Google Sheets, or StatCrunch. Correct the following before analysis:

  1. Height Variable: Convert all heights to total inches (e.g., 5'7" becomes 67).
  2. Pulse Variable: Remove any text (like "bpm") so the column contains only numbers.
  3. Categorical Cleanup: Check "Eye Color." If a color has fewer than 2 entries, rename it to "Other."

Step 2: Organizing the Data

  • Create distribution tables for the Height_Inches variable.
  • Requirement: The tables must include both Frequency and Relative Frequency.
  • Grouping: You must group this data by Gender (e.g., separate columns or sections for Men and Women) to facilitate comparison.

Step 3: Visualizing the Data

Create the following graphs. Ensure every graph has a title and labeled axes.

  1. Histogram: Use your frequency distribution to create a histogram for Height_Inches.
  2. Bar Graph or Pareto Chart: Create a bar graph for the Math Anxiety Rating. (Note: Pie charts are not accepted for this assignment).
  3. Comparative Boxplots: Create side-by-side boxplots for Height_Inches separated by Gender.

Step 4: Numerical Summaries

Calculate the following statistics for the full class Height_Inches:

  • Mean (x̄)
  • Median (M)
  • Mode
  • Range
  • Standard Deviation (s)
  • Five-Number Summary: Min, Q1, Median, Q3, Max.

Step 5: The Personal Connection

  • Calculate: Find the z-score for your own height using the class mean and standard deviation.
  • Requirement: You must include the z-score calculation (show the formula with your numbers plugged in) as well as the final result.
  • Interpret: Explain what this z-score tells you. Are you considered "unusual" (more than 2 standard deviations away from the mean)?

Step 6: Methods Section

Write a brief paragraph explaining the tools and steps you used to calculate the statistics above. Crucially, you must also comment on any data cleanup challenges you encountered (e.g., dealing with inconsistent units, removing text from numerical columns, or handling missing data).

Phase 3: Simulation & Distributions

Focus: Randomness, Binomial models, and Confidence Intervals.

Student Instructions

Step 1: Binomial Simulation

Simulate a random selection of students using a coin toss.

  1. Assume P(Female) = 0.5. Flip a coin 30 times (Heads = Female). Record your number of Heads.
  2. Calculate the Expected Number (μ = np) and Standard Deviation (σ = √(np(1-p))).
  3. Is your coin flip result "unusual" (z-score > 2 or < -2)?

Step 2: Confidence Intervals

  1. Proportion: Construct a 95% Confidence Interval for the proportion of students with Blue Eyes. Check conditions: is np(1-p) ≥ 10?
  2. Mean: Construct a 90% Confidence Interval for the mean Commute Time.
  3. Interpretation: Interpret both intervals in the context of the problem.

Step 3: Methods Section

Briefly describe how you performed the simulation and which tools were used for the CI calculations.
